## The measurement rules, and where each one bit

1. **`#root` never scrolls.** Nothing in the gate reads `docScrollY` or compares
   `documentElement.scrollHeight` with `clientHeight`. Recorded so the next author does not have to
   rediscover it: with the menu open, `docScrollY` is 0 and the document's max scroll is 0 at all
   three geometries **while the sheet still has 944px of travel left at 320x568**. A check reading the
   document would have called this entire screen unreachable — the same shape as the two false P0s.
   The real scroller is `[data-ct="menu-sheet"]` itself; its parent, the fixed overlay, has
   `maxScroll: 0` and is not the scroller.
2. **Transforms are paint.** No piece rect is asserted anywhere; the Look preview is measured by its
   cells' background colours.
3. **`locator.click()` auto-scrolls.** Every reachability claim is measured by `REACH()` *before* any
   tap, and every drive tap is a programmatic `el.click()` that is never treated as evidence.
   This one bit during the run: the first version of TC-MN-032 used `b.tapCt('look-pc-merida')`,
   which clicks at layout coordinates — and the piece chips are below the fold, so the click landed
   in empty space and the case went **red against a working build**. Caught because the negative
   controls had not been run yet and the green was not yet believed.
4. **`L.over()` is blind to `position:fixed` children of `#root`.** The menu overlay is exactly such
   a child, so `L.over()` is not called anywhere in this file — it would be measuring the home screen
   behind the sheet.
5. **Check the stamp.** Printed on every launch; `#915` throughout.

A sixth thing bit, from CLAUDE.md rather than the charter: **a bad selector is a reading, not a
measurement.** TC-MN-037's first version took `row.querySelectorAll('button')` from the `SKIN`
header's parent — but that flex container also holds every toggle row, the five piece chips and the
four coach chips, so it returned **nineteen** buttons and reported "three skins" as red on a build
with exactly three skins. Fixed by naming what a skin card actually is (a direct-child button with
three or more spans) rather than its container. Same family as the #394 trap.

// Everything that escapes the viewport sideways. Nothing in this sheet scrolls horizontally on purpose, so
// unlike gate 45 there is no scroller exemption here: any element past the edge is a finding.
const HSPILL=(b)=>b.page.evaluate(()=>{

// (rule 3) a drive tap: programmatic, deliberately NOT locator.click(), and never evidence of reachability.
